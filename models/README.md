# Model integration slot

Place your trained model artifacts in this directory. This starter ZIP intentionally
does not contain your trained models.

Examples of files you might add:
- `isolation_forest.joblib`
- `ndvi_autoencoder.keras`
- `scaler.joblib`

Update `app.py` with the exact loading/inference code for your model formats.
Do not assume these example filenames match your actual artifacts.
